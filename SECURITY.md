# Security policy

This repository contains third-party Hermes plugins that process messages,
attachments, callbacks, and API credentials.

Do not report a vulnerability in a public issue if it includes a token, private
message, personal identifier, or an exploitable request. Use GitHub's private
vulnerability reporting/security advisory flow when it is enabled for the
repository, or contact the maintainer through the GitHub profile.

Please include the affected version, deployment mode, a minimal reproduction,
and the impact. Redact credentials and private data from all reports.

Supported security fixes are best-effort for the latest tagged release and the
current default branch. Live platform behavior can also depend on MAX/VK API
changes and the operator environment.
