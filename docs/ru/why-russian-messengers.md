# Зачем поддержка VK и MAX в Hermes Agent

## Проблема

[Hermes Agent](https://github.com/NousResearch/hermes-agent) — это персональный AI-агент с долговременной памятью, который из коробки поддерживает Telegram, Discord, Slack, WhatsApp, Signal и ряд азиатских мессенджеров. **В этом списке нет ни одного российского сервиса.**

Для пользователя в РФ это создаёт практическую проблему: Telegram периодически замедляется или ограничивается, а другие поддерживаемые мессенджеры (Discord, Signal, WhatsApp) то и дело попадают под локальные блокировки. Стандартный обходной путь — VPN — сам по себе уязвим: VPN-сервисы регулярно блокируются, их использование юридически в серой зоне, а главное — VPN не решает проблему в моменты, когда оператор переходит на режим ограниченной связности и пропускает только трафик из «белого списка» Роскомнадзора.

## Что такое «белый список»

При региональных ограничениях связи (учения, политические события, технические сбои) российские провайдеры могут переходить в режим, при котором доступны только сервисы из заранее согласованного перечня. В этот перечень традиционно входят:

- **VK** (vk.com) — социальная сеть и мессенджер, 90+ млн MAU в РФ.
- **MAX** (max.ru) — мессенджер, поддерживаемый государством, развиваемый VK Tech как национальная альтернатива Telegram/WhatsApp.
- Госуслуги, Сбер, отдельные банки, Яндекс.

Сервисы вне списка — включая Telegram, Discord, Signal, WhatsApp — в такие моменты недоступны даже через VPN, потому что блокируется сам зарубежный трафик, а не конкретный домен.

## Решение

Эти два плагина (`plugins/max` и `plugins/vk`) дают Hermes Agent каналы в обоих whitelisted-сервисах. Ваш агент остаётся доступным:

| Сценарий | Telegram | VK / MAX |
|----------|----------|----------|
| Нормальная связь | работает | работает |
| Локальное замедление Telegram | деградирует | работает |
| Блокировка Telegram | требует VPN | работает |
| Региональный «whitelist mode» | недоступен | работает |

## Не «вместо», а «вдобавок»

Hermes Agent умеет работать с несколькими платформами одновременно. Рекомендуемая конфигурация:

- **Telegram** — основной канал, пока он работает (лучший UX, голос, реакции, файлы).
- **MAX** — резервный, гарантированно доступен под whitelisted-режимом.
- **VK** — дополнительный, для общения через привычное приложение.

Сессии в Hermes ключуются по `(platform, chat_id)`, поэтому переключение между каналами не путает память агента — каждая сессия независима, как с разными собеседниками.

## Юридическая чистота

VK и MAX — российские юридические лица с реестровым ПО. Установка ботов через официальные API (`@MasterBot` для MAX, `vk.com/dev` для VK) **не требует VPN, не нарушает 149-ФЗ и не подпадает под ограничения по использованию VPN-сервисов**. Это делает решение пригодным для корпоративных установок Hermes Agent в РФ.

## Что НЕ решают эти плагины

- Не заменяют end-to-end шифрование Signal/WhatsApp — VK и MAX используют клиент-серверное шифрование с возможностью раскрытия по запросу. Если ваш use-case требует strong privacy — продолжайте использовать Signal/Telegram, эти плагины как дополнительный канал.
- Не дают доступа к моделям, заблокированным на стороне провайдера (OpenAI, Anthropic) — за это отвечает само ядро Hermes Agent и ваш `OPENROUTER_BASE_URL` / `ANTHROPIC_BASE_URL`. Для российских установок имеет смысл также настроить локальные модели (Nous Portal, NVIDIA NIM, vLLM) или использовать прокси для зарубежных API.
