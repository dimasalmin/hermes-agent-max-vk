# Интерактивные кнопки MAX

Плагин MAX подключает штатные интерактивные интерфейсы Hermes:

- `send_clarify`: кнопка для каждого варианта и кнопка `Другое` для ввода текста;
- `send_exec_approval`: разовое разрешение, разрешение на сессию, постоянное
  разрешение и запрет;
- `send_slash_confirm`: разовое подтверждение, постоянное подтверждение и отмена.
- `send_model_picker`: выбор провайдера, затем модели через штатный callback
  Hermes.
- `send_choice_picker`: конечный выбор для `/reasoning` и других поддерживаемых
  Hermes команд. Значения и обработчик предоставляет Hermes, а не LLM.

Состояние кнопок хранится только в памяти процесса. Callback имеет короткий TTL
по умолчанию 600 секунд, одноразовый opaque-токен и привязку к исходным
`user_id` и `chat_id`. После перезапуска gateway старые кнопки недействительны;
это предотвращает сохранение ложного approval без живого wait-примитива Hermes.
TTL можно изменить через `MAX_CALLBACK_TTL_SECONDS`.

Нажатие обрабатывается так: MAX присылает `message_callback`, плагин проверяет
allowlist и токен, разрешает штатный примитив Hermes, затем вызывает официальный
`POST /answers?callback_id=...` и убирает клавиатуру из prompt-сообщения.
Для `/model` этот же механизм заменяет клавиатуру провайдера на список моделей,
а выбор модели вызывает штатный `on_model_selected` Hermes.

Для direct message пользователь определяется автоматически по `chat_id`. Для
группы callback привязывается к chat ID и сроку; уточнение привязано к
инициатору, а approval, выбор модели и управляющие команды доступны только
`MAX_ADMIN_USERS`. Чужое, повторное или истёкшее нажатие не выполняет действие.

Обычные кнопки меню не вызывают LLM напрямую: они преобразуются в штатную
slash-команду Hermes. Ошибка регистрации меню не отключает MAX-канал.

Выбор уровня привязан к инициатору, чату, сессии, запросу и сообщению с кнопками.
Новый допущенный запрос в том же диалоге консервативно отменяет старый выбор,
поэтому кнопку, показанную до `/new` или `/resume`, нельзя применить позже.
Другое нажатие того же выбора не выполняет действие повторно, даже если кнопка
другая. Отмена не меняет настройку. В группах требуется администратор, но даже
другой администратор не может выбрать уровень за инициатора.

Состояние ограничено восемью ожидающими выборами и 58 вариантами на выбор;
лишние/некорректные варианты отклоняются, не обрезаются молча. После сбоя
обработчик не запускается автоматически ещё раз. Обновление штатных команд
не изменяет глобальный язык: русский контекст MAX сбрасывается после вызова,
включая исключения; чужой профиль не получает область секретов по умолчанию.

Проверка перед установкой:

```powershell
python -m pytest -q
```
