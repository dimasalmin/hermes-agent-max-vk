# Обновлённый Edge TTS без изменения Hermes

Это необязательная настройка **профиля Hermes**, а не автоматическое действие
MAX-плагина. Если профиль обслуживает также Telegram, выбор TTS изменится
для обоих каналов. Сначала получите согласие владельца и сохраните конфигурацию.

## Когда Нужна Настройка

При проверке 17 октября 2026 встроенный Edge с закреплённым пакетом 7.2.7
возвращал HTTP 403. [Выпуск Edge TTS 7.3.0](https://github.com/rany2/edge-tts/releases/tag/7.3.0)
добавляет поддержку нового Sec-MS-GEC v2. На проверенной установке 7.3.0
реально создал речь; это не гарантия доступности внешнего сервиса в любой сети.
Текст для озвучивания передаётся сервису Microsoft, синтез не является локальным.

Не меняйте зависимости внутри управляемой установки Hermes и не редактируйте
ядро ради этой настройки. Используйте отдельное окружение `edge-tts==7.3.0`,
не выбранное менеджером пакетов как основное окружение Hermes. Разместите
`scripts/edge_tts_command.py` в постоянном каталоге вне development-checkout.
Зафиксируйте версию пакета, абсолютный путь интерпретатора и SHA-256 скрипта.

## Конфигурация

Требуется установленный Hermes с поддержкой `tts.providers.<имя>.type: command`.
Контракт проверен с настоящим Hermes 0.21.6. Отсутствие такого механизма
в другой версии — повод остановить настройку, не изменять её ядро.

Пример отдельного провайдера; пути заменяют на проверенные абсолютные пути:

```yaml
tts:
  provider: edge73
  providers:
    edge73:
      type: command
      command: /absolute/edge-env/bin/python -B /absolute/tts-release/edge_tts_command.py --input {input_path} --output {output_path} --format {format} --voice {voice} --speed {speed}
      voice: ru-RU-DmitryNeural
      speed: 1.1
      output_format: mp3
      voice_compatible: true
      max_text_length: 5000
      timeout: 120
```

Сохраните **собственные** прежние голос и скорость; значения выше — пример.
Если скорость задана только на общем уровне `tts.speed`, не добавляйте
переопределение в `providers.edge73`: тогда сохраняются штатные изменения
скорости при вызове инструмента. Старый блок `tts.edge` оставьте для отката.
Имя `edge` зарезервировано встроенным провайдером, переопределить его нельзя.
Не заменяйте целиком существующий раздел TTS и другие пользовательские провайдеры.

Текст читается из временного UTF-8 файла; он не вставляется в shell-команду.
Штатный renderer Hermes экранирует значения placeholders. Скрипт проверяет
версию 7.3.0, скорость 0,25–4,0, непустой текст и формат MP3. На один вызов
установлен общий предел 90 секунд; файл публикуется только после успешного
синтеза, частичный результат удаляется. Ошибка не содержит текста или URL.

Сам скрипт создаёт **только MP3**. При `voice_compatible: true` штатный Hermes
использует ffmpeg для Ogg/Opus. Нужен доступный рабочий ffmpeg; отсутствие
конвертации не следует скрывать переименованием MP3 в `.ogg`. Длинный текст
Hermes делит на части, 5000 символов — предел части, не всего ответа.
Не добавляйте `env_passthrough` с секретами: этот провайдер их не требует.

## Проверка И Откат

1. Сохранить приватную копию `config.yaml`, хеши ядра/lockfiles и текущий TTS.
2. В отдельном временном `HERMES_HOME` проверить настоящий
   `text_to_speech_tool`, а не только прямой вызов библиотеки.
3. Проверить ffprobe: фактические Ogg/Opus, непустое аудио, флаг голосовой
   доставки; отдельно проверить контексты `max` и `telegram`.
4. Атомарно изменить только TTS основного профиля в свободное окно. На
   проверенном Hermes конфигурация перечитывается по изменению файла;
   перезапуск не потребовался. Не переносите это утверждение на любую версию.
5. Повторить синтез из рабочего профиля; отправить владельцу одну запись
   в MAX и проверить её обратное скачивание. MAX может перекодировать аудио.
6. На телефоне проверить воспроизведение и ответ на просьбу «Ответь голосом».
   Формат для Telegram проверяется отдельно от фактической доставки в Telegram.

Для отката вернуть **только прежний раздел TTS** из копии с проверкой, что
другие настройки не изменяются. Не восстанавливать старый полный config
поверх более новых изменений. Старый `edge` может снова дать прежний 403;
откат конфигурации не означает восстановления внешнего сервиса.
Плагин, SQLite inbox, сессии и основной пакетный environment для этого
не переключают. Отдельный Edge-environment не удаляют до завершения приёмки.

Это изменение исходящего синтеза. Оно не исправляет неполные входящие события
голоса/кружков MAX, в которых Bot API не передал файл.
