# Команды MAX

Нативное меню, быстрый экран `/menu` и меню подключённого через доверенный
маршрутизатор бота должны строиться из одного `_max_commands()` установленного
плагина. Реестр установленного Hermes определяет доступность команд;
MAX отображает подсказки, но не заменяет обработчики Hermes.

## Основной Набор

| Команда | Действие |
|---|---|
| `/menu` | Быстрые кнопки MAX и краткая справка |
| `/commands [страница]` | Полный постраничный каталог команд и навыков Hermes |
| `/help` | Штатная справка Hermes |
| `/status` | Состояние сессии, модель и контекст |
| `/new [имя]` | Новая сессия; текущая задача может быть прервана |
| `/stop` | Остановка текущей задачи и фоновых процессов согласно Hermes |
| `/model` | Выбор модели; текстовые аргументы поддерживаются Hermes |
| `/goal` | Состояние и управление текущей целью, не автоматический GUI-мастер |
| `/reasoning` | Кнопки выбора уровня рассуждений |
| `/compress` | Сжатие контекста; `--preview` — просмотр без сжатия |
| `/sessions` | Список доступных предыдущих сессий |
| `/resume [имя]` | Список именованных сессий либо переключение на выбранную |
| `/retry` | Повтор запроса к модели, не повторная доставка прежнего ответа |
| `/undo [N]` | Возврат на N пользовательских ходов, не откат файлов |
| `/agents` | Активные агенты и задачи |
| `/whoami` | Доступ пользователя к командам |
| `/queue [текст/подкоманда]` | Просмотр и управление очередью запросов |
| `/maxstatus` | Транспорт, резерв и устойчивая очередь MAX, не статус модели |

## Рассуждения

`/reasoning` использует варианты и callback настоящего Hermes. Выбор уровня
обычно относится к текущей сессии; операция не дописывает `--global`.
Набор поддерживаемых уровней зависит от выбранной модели и маршрута.
Если Hermes сообщает, что внутренний уровень преобразуется в другой уровень
API, это предупреждение сохраняется, а не скрывается переводом кнопки.

```text
/reasoning high
/reasoning none
/reasoning show
/reasoning hide
/reasoning reset
```

`none` отключает рассуждения, насколько это допускает модель. `show`/`on`
показывают вывод рассуждений, `hide`/`off` скрывают его: это не выбор усилия.
`reset` снимает сессионное переопределение. `--global` — отдельное явное изменение
профиля и может затронуть другие его каналы. Неподдерживаемые аргументы не
следует добавлять в кнопки только по подсказке старой документации.

Старый выбор становится недействителен после нового запроса, перезапуска,
истечения срока или уже выполненного выбора. Откройте `/reasoning` заново.
Нажатия не передаются модели как новое сообщение.

## Общий Бот

Меню общего бота глобально для его MAX-токена. Им должен управлять один
доверенный компонент, а не каждый профиль независимо. Он регистрирует
канонический список, проверяет фактический `GET /me` и не сообщает об успехе,
если запрос не дошёл до MAX. Отдельный профиль не должен менять общее меню.
После обновления генератора обновите и доверенный список маршрутизатора.

## Webhook И Резерв

`/maxstatus` различает основной Webhook и временный резервный polling.
Переход в резерв не означает потерю ответа сам по себе. Проверяются HTTPS-вход,
туннель, подписка и очередь; polling и Webhook не должны работать одновременно.
При настроенном автовозврате здоровый вход должен вернуть основной транспорт.
Не удаляйте чужие подписки и не запускайте второй `/updates` ради диагностики.

## Основания

- [Интерфейсы адаптера Hermes](https://github.com/NousResearch/hermes-agent/blob/main/gateway/platforms/ADDING_A_PLATFORM.md):
  штатный `send_choice_picker`, текстовый fallback и внешний плагин без правок ядра.
- [Меню MAX](https://dev.max.ru/docs-api/methods/PATCH/me/commands): до 32 подсказок.
- [Клавиатура MAX](https://dev.max.ru/docs-api/use-cases/sending-messages/keyboard/):
  отдельные inline-кнопки и callback, не реализация логики slash-команд.
