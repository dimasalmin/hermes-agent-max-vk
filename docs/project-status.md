# Состояние Интеграций

MAX и VK реализованы как внешние плагины Hermes Agent. Они не требуют
копирования кода в ядро и имеют отдельный жизненный цикл обновления.

MAX поддерживает текст, команды, кнопки и транспорт изображений, документов,
аудио и видео. Возможности обработки содержимого зависят от установленного
Hermes Agent и его провайдеров. MAX Bot API не гарантирует наличие всех видов
пересланных вложений; недоступное медиа не следует выдавать за успешно прочитанное.

Webhook — основной транспорт постоянной эксплуатации. Резервный polling
и автоматический возврат, если они поддерживаются выбранной версией, включаются
явно и требуют испытаний общего inbox, подписок, безопасности входа и отката.
См. [инструкцию](ru/max-setup.md).

Локальные тесты и проверки настоящего загрузчика не заменяют живую приёмку.
Для неё используйте отдельного тестового бота, синтетические сообщения,
одного получателя событий и заранее проверенный откат.

Отчёты о частных инсталляциях, персональные сообщения и данные устройств
не входят в публичную документацию. См. [политику публикаций](publication-privacy.md).
